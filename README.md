# Recursive Musicology

**A SCIGEN-inspired procedural writing system for generating fictional music-theory papers, diagrams, citations, and adjacent speculative documents.**

Recursive Musicology treats academic prose as a playable medium. A seeded grammar engine assembles convincing-looking analytical claims, bibliographies, equations, diagrams, and institutional language into reproducible documents whose coherence can be tuned from dry scholarship to total epistemic collapse.

> **Note:** Every generated manuscript is fictional. This project is an artwork, parody, and creative-coding experiment—not a source of factual scholarship or legitimate academic citations.

## What it does

- Generates long-form fictional music-theory papers across numerous analytical traditions
- Uses deterministic seeds, so the same settings reproduce the same document
- Adds adjustable **madness** and **semantic drift** controls
- Produces author, co-author, institution, abstract, section, diagram, equation, and bibliography structures
- Includes alternate procedural-writing environments for horror manuscripts, obsessive diaries, underground-culture dispatches, and satirical schemer dossiers
- Exports generated documents as PDFs
- Builds as a self-contained single-page HTML application

## Concept

The project takes inspiration from **SCIGEN**, the well-known context-free grammar system that generated computer-science papers, and relocates its central provocation into musicology and creative writing.

Rather than merely imitating academic typography, Recursive Musicology explores how authority is manufactured through disciplinary vocabulary, citation density, diagrammatic evidence, institutional formatting, and the rhythm of scholarly qualification. Its controls expose coherence itself as an aesthetic parameter.

## Tech stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Seeded procedural grammar systems
- SVG/React-generated analytical diagrams
- html2pdf.js and jsPDF
- GitHub Actions deployment to GitHub Pages

## Run locally

You need Node.js 22 or newer.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

The build is emitted to `dist/` as a self-contained HTML application.

## Deploy on GitHub Pages

A Pages deployment workflow is already included.

1. Upload the contents of this folder to a new GitHub repository.
2. Make sure the default branch is named `main`.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **GitHub Actions**.
5. Push a change or manually run **Deploy to GitHub Pages** from the Actions tab.

## Creative-technologist framing

Recursive Musicology is simultaneously:

- a procedural text engine
- an interface artwork
- a parody of institutional authority
- a deterministic generative system
- an audiovisual-adjacent publishing instrument
- a study of how formatting and jargon simulate knowledge

## Possible extensions

- Shareable URLs that encode seeds and generator parameters
- Generated cover pages and institutional seals
- Web Audio sonification of paper structure and citation density
- A corpus editor for adding new disciplinary lexicons
- “Peer review” generated by a second adversarial grammar
- Exportable JSON provenance for each manuscript
- A public gallery of unusually coherent or catastrophically unstable papers

## Responsible use

Do not submit generated text as academic work, impersonate real scholars, or present invented citations as genuine sources. The generator is intended for art, parody, experimentation, and critical reflection on textual authority.
